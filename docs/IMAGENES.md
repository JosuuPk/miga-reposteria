# Guía de imágenes (prompts para ChatGPT)

La web es oscura, con luz frambuesa y caramelo. Las fotos deben tener **fondo cacao casi negro** para fundirse con la página.

## Cómo generarlas
1. Abre **una sola conversación** en ChatGPT y genera las diez imágenes ahí, en orden. Así mantienen la misma luz.
2. Copia cada prompt completo, tal cual.
3. Si alguna sale distinta, escribe: "Repítela con el mismo fondo oscuro y la misma luz que la primera imagen".
4. Revisa que no haya letras, logotipos ni manos.

## Cómo entregarlas
- Descárgalas en PNG o JPG y guárdalas con el nombre exacto indicado.
- `portada.png` y `compartir.png` van en `public/images/`. Las demás en `public/images/productos/`.
- Avísame y yo las recorto, las optimizo y las conecto.

Al ser generadas con IA, la web las rotula como **"Imagen ilustrativa"**: no se presentan como trabajos reales de un negocio.
